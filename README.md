# Public procedures guide MCP server

MCP server that finds a public procedure, its requirements and where to complete it, in plain Spanish.

## Overview

Indexes the national procedures guide so an agent can tell a resident exactly what a procedure needs and where to do it, linking the official page.

## Tools

- `find_procedure`
- `procedure_requirements`
- `procedure_channels`

## Interfaces

Protocol: `mcp`. Languages: es.
